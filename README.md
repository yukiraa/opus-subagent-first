# opus-subagent-first

A Claude Code skill that makes Opus act as orchestrator and delegate bounded subtasks to Haiku/Sonnet.

## Install

Copy the `opus-subagent-first` folder into your Claude Code skills directory:

```
~/.claude/skills/opus-subagent-first/SKILL.md
```

On Windows, that is `C:\Users\<you>\.claude\skills\`. Restart Claude Code (or start a new session) so the skill is picked up.
